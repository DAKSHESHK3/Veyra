SYSTEM SPECIFICATIONS & FAQ

RFC • PROTOCOL ASSURANCE
SPEC // 001

Do I need to install Python, OpenCV, or Tkinter?

No. The entire system is built on modern web primitives. Inference executes client-side via WebGL 2.0 shaders and WebAssembly. No local Python interpreter, GPU drivers, or terminal commands are necessary.

ZERO RUNTIME FOOTPRINT
SPEC // 002

Are video frames uploaded to an external server?

Never. Camera sensor frames are strictly retained in ephemeral browser RAM for matrix manipulation and instantly discarded. Only irreversible 128-float mathematical vectors and timestamp records ever reach the database.

AIR-GAPPED SENSOR FRAMES
SPEC // 003

Can a student be marked present twice in a lecture?

Impossible. The front-end memory bus buffers already-identified UUIDs to prevent repeated trigger pings, while Postgres enforces a compound primary constraint UNIQUE(session_id, student_id) at the database layer.
